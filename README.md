## Selected work

### RAG Retrieval & Generation Benchmark

![LLMs](https://img.shields.io/badge/LLMs-111827?style=flat-square&logo=openai&logoColor=white)
![Qdrant](https://img.shields.io/badge/Qdrant-DC244C?style=flat-square&logo=qdrant&logoColor=white)
![Information Retrieval](https://img.shields.io/badge/Information_Retrieval-4F46E5?style=flat-square&logo=elasticsearch&logoColor=white)
![Evaluation](https://img.shields.io/badge/Evaluation-047857?style=flat-square&logo=weightsandbiases&logoColor=white)

> A reproducible benchmark exploring how retrieval choices and model configurations affect the quality of a RAG system.

I compared BM25 with dense retrieval using Qdrant, then evaluated retrieval performance on 100 queries with Precision@k, Recall@k, and MRR. I also benchmarked Granite 3B and 8B models for answer correctness, grounding, citation accuracy, and inference time.

The project examines a practical question: how much retrieval and generation quality can be improved before the additional computational cost stops being worthwhile?

### Spiridon - Graph-Based Artifact Classification

![PyTorch Geometric](https://img.shields.io/badge/PyTorch_Geometric-EE4C2C?style=flat-square&logo=pytorch&logoColor=white)
![Graph Neural Networks](https://img.shields.io/badge/Graph_Neural_Networks-2563EB?style=flat-square&logo=graphql&logoColor=white)
![Knowledge Graphs](https://img.shields.io/badge/Knowledge_Graphs-018BFF?style=flat-square&logo=neo4j&logoColor=white)
![BERT](https://img.shields.io/badge/BERT-FFD21E?style=flat-square&logo=huggingface&logoColor=black)

> My graduation research project, developed during an internship at **LS2N, Nantes University**.

I represented archaeological artifacts as heterogeneous graphs connecting objects, attributes, and functions. I investigated ontology integration and compared MLP and R-GCN architectures using multi-hot and BERT-based feature representations.

The best model reached **98.33% classification accuracy** in the reported experimental setting on a dataset of more than **11,000 artifacts**.

**[View repository →](https://github.com/mohammedhachoud/Spiridon)**
